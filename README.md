## Лабораторная работа №4

**Тема:** Изучение современного CSS и основ ООП на JavaScript.
**Задание:** в качестве основы скопировать web-сайт из лабораторной работы №2, модернизировать его с использованием технологий HTML, CSS и JavaScript и загрузить проект в репозиторий.

В работе модернизирован сайт кофейни «Аромат»:

- страница `index.html` — вёрстка с помощью Flexbox;
- страница `menu.html` — вёрстка с помощью CSS Grid;
- все цвета вынесены в CSS-переменные в `:root` (`style.css`);
- реализована CSS-анимация логотипа и гирлянды;
- на странице `contacts.html` добавлена форма с полями `text`, `email`, `select`, `textarea`, `checkbox`;
- при отправке формы создаётся объект класса `ContactRequest` и вызывается метод `print()` для вывода данных в консоль.
